# 数字照片墙 · 旅行明信片

完全离线的旅行明信片制作网页。直接在浏览器打开 `index.html` 即可使用，无需服务器或安装依赖。

## 功能

- 复古旅行、极简现代、手账拼贴三个模板，切换时保留编辑内容。
- 上传 JPG、PNG、HEIC/HEIF 照片，拖动和缩放调整构图。
- 照片滤镜、模板固定文字、三款邮戳以及旅程地点。
- 撤销、最终预览，将作品保存到数字照片墙。
- 点击顶部“数字照片墙”或打开 `wall.html` 查看作品。
- 手机和电脑响应式布局。

作品保存在当前浏览器的 IndexedDB 中，不上传网络。清除浏览器数据会删除本地作品；使用同一浏览器及原始项目路径查看照片墙。

## 项目文件

- `index.html`、`styles.css`、`app.js`：明信片编辑器。
- `wall.html`、`wall.css`、`wall.js`：数字照片墙。
- `assets/heic2any.min.js`：内置 HEIC 解码组件，许可见 `assets/heic2any.LICENSE.md`。
